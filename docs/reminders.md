# Напоминания о подтверждении записи

## Логика

Для записей со статусом **Записан** (`BOOKED`), у которых визит в ближайшие N часов
(`APPOINTMENT_REMINDER_HOURS`, по умолчанию 48):

1. пациенту уходит уведомление `APPOINTMENT_CONFIRM_REQUEST` (сейчас stub);
2. сотруднику ставится задача «Подтвердить запись (напоминание)», если её ещё нет;
3. обновляется следующий шаг обращения.

Повторно на ту же запись напоминание не шлётся (идемпотентность по `Notification`).

## Где запускается

- автоматически при открытии **Записи** и **Контроль**;
- кнопка «Запустить напоминания» / «Напоминания записей».

## ENV

```
APPOINTMENT_REMINDER_HOURS=48
```
