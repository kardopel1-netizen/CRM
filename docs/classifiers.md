# Классификаторы

## Каналы обращения

телефон, сайт, форма, мессенджер, соцсети, реклама, рекомендация, существующий пациент, другое.

Для рекламы дополнительно: `sourceSystem` → `sourceCampaign` → `sourceAd` + UTM-поля.

## Направления услуг

терапия, хирургия, ортопедия, ортодонтия, имплантация, гигиена, детская, консультация.

## Причины потери / отказа

высокая стоимость; выбрал другую клинику; неудобное время; расположение; не удалось связаться; отложил лечение; консультация не нужна; противопоказания; другое.

## Причины отмены / переноса записи

пациент занят; самочувствие улучшилось; стоимость; страх; перенос клиникой; врач недоступен; другое.
