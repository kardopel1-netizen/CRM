# Слияние дублей пациентов

## Зачем

Повторные обращения не должны плодить неконтролируемые карточки. Если дубль всё же появился — карточки объединяют вручную.

## Где

- Список пациентов → **Слияние дублей**
- Карточка пациента → **Слить с дублем**
- `/patients/merge`

## Что происходит

1. Выбирается **основная** карточка (остаётся).
2. Выбирается **поглощаемая** (удаляется).
3. Переносятся: обращения, записи, контакты, уведомления.
4. Телефон/email можно взять из любой из двух карточек.
5. В аудит пишется событие `merged`.

## Возможные дубли

Система подсказывает группы с одинаковым телефоном или одинаковыми фамилией+именем.
