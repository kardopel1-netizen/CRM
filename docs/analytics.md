# Аналитика и дашборд

## Дашборд `/dashboard`

- **Оператор** — свои показатели (назначенные обращения и задачи).
- **Руководитель / управляющий / собственник / админ** — вся клиника.

KPI:

- обращения сегодня / за 7 дней;
- конверсия обращение → запись → визит;
- доля потерь;
- средний первый ответ и нарушения SLA;
- риски (без следующего шага, без контакта, неявки);
- нагрузка сотрудников.

## Отчёты `/reports`

Те же данные + разрезы по каналам, причинам потерь, сотрудникам и **маркетингу (UTM / кампании)** за 30 дней.

## Аудит `/audit`

Журнал `AuditLog` для ролей руководитель / управляющий / собственник / админ.
