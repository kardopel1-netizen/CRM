# Аналитика и дашборд

## Дашборд `/dashboard`

Доступ: руководитель, управляющий, собственник, админ.

KPI без погружения в карточки:

- обращения сегодня / за 7 дней;
- конверсия обращение → запись → визит;
- доля потерь;
- средний первый ответ и нарушения SLA;
- риски (без следующего шага, без контакта, неявки);
- нагрузка сотрудников.

## Отчёты `/reports`

Те же данные + разрезы по каналам, причинам потерь и сотрудникам.
