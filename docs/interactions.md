# Контакты и первый ответ

## Журнал контактов

На карточке пациента оператор фиксирует:

- звонок;
- сообщение;
- комментарий;
- email.

Звонок/сообщение по умолчанию считаются **попыткой связи**:

- увеличивается `contactAttempts`;
- если `firstContactAt` пустой — ставится сейчас;
- если этап «Новое обращение» — автопереход на «Контакт установлен» (если переход разрешён).

## После визита (ARRIVED)

При статусе записи «Пришёл»:

1. первичное обращение закрывается как `WON`;
2. открывается обращение в воронке **После первичного приёма**;
3. создаётся задача «План лечения после первичного приёма».
